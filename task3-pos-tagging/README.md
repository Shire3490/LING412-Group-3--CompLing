# Task 3: POS Tagging and Inter-Annotator Agreement

This folder contains a POS tagset, annotation files, agreement calculation, reconciled gold data, and a baseline tagger.

## Important status

The current annotation files are **development placeholders generated by documented heuristics**. They are useful for testing the pipeline, but they must be replaced or independently checked by two human annotators before final submission. Do not describe the generated files as genuine independent human annotations.

## Workflow

```bash
cd task3-pos-tagging/scripts
python3 build_annotations.py
python3 evaluate_agreement.py
python3 evaluate_tagger.py
```

The scripts use the first 600 tokens from Task 1 as the annotation sample. The remaining tokens are not used in the sample annotation.

## Outputs

- `data/annotator_a.csv`: first provisional annotation
- `data/annotator_b.csv`: second provisional annotation
- `data/gold.csv`: reconciled development gold data
- `results/agreement.txt`: Cohen's kappa and agreement counts
- `results/tagger-evaluation.txt`: baseline tagger accuracy and errors

Replace the provisional annotation files with independent human annotations, preserving the columns and token order, before reporting final results.
