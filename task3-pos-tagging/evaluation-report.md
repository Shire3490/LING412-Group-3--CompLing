# Task 3 Evaluation Report

## Dataset

A 600-token sample was extracted from the Task 1 processed corpus. The sample contains sentence and token identifiers so that both annotators label the same sequence.

## Annotation status

The current annotation files were generated by two documented heuristic passes to validate the pipeline. They are not final independent human annotations. Before submission, two group members must independently annotate the same 600 tokens without seeing each other's labels, then replace `annotator_a.csv` and `annotator_b.csv` while preserving the schema.

## Tagset

The project uses the tags documented in `tagset.md`: `NOUN`, `PROPN`, `VERB`, `ADJ`, `ADV`, `PRON`, `DET`, `ADP`, `CONJ`, `NUM`, `PART`, and `X`.

## Inter-annotator agreement

The provisional annotations contain 600 tokens.

- Observed agreement: 99.00%
- Cohen's kappa: 0.9867
- Disagreements: 6

The kappa calculation estimates agreement beyond chance using the observed tag distributions. The provisional value indicates very high consistency between the two heuristic passes, but it must not be reported as human inter-annotator agreement. The final report should replace it with the result from the two independent human annotations.

## Gold-standard data

`data/gold.csv` currently uses annotator A's labels as the provisional reconciled dataset. After human reconciliation, update this file so every disagreement has a documented final decision.

## Baseline tagger

The baseline is a word-to-tag majority lookup trained on 480 gold tokens and evaluated on 120 held-out tokens.

- Accuracy: 70.00%

The tagger performs poorly on unseen words because it falls back to the most frequent training tag. Common recorded errors involve proper names, ambiguous words, and words whose surface endings resemble verbs, such as `Uingereza`, `Burnham`, `yako`, and `miili`.

## Limitations

The sample is small, the provisional labels are heuristic, and the baseline does not use sentence context, morphology, or a statistical sequence model. The reported results are therefore development results. Final submission results require independently produced human annotations and a clearly documented reconciliation process.
